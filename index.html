风险提示

  1. 随时会变：注册额度、签到奖励、可用模型、倍率都可能随时调整，以站点自己的公告为准。
  2. 可能跑路：公益站可能限流、关停或直接跑路，不要充值大量资金，不要当成唯一依赖。
  3. 隐私风险：中转站能看到你发过去的全部请求内容，涉密代码、生产环境凭据、客户数据不要经过第三方中转。
  4. 账号风险：部分站点要求 GitHub 老号注册，注册行为本身也有被平台风控的可能，自行权衡。
  5. 邀请说明：页面内注册链接含邀请参数（aff），属于作者推广链接，一般不影响你获得的额度，通常双方都有奖励。
  6. 出问题找站点：充值、退款、封号等问题请找站点自己的支持渠道，本站无法代为处理。
